# Assured assessment: Graphical analysis

Analysing DAGs generated by domain experts, along with details of the modelling protocol for eliciting knowledge from domain experts with the use of causal diagrams.

## Modelling Protocol and support materials

The **modelling protocol** is in a pdf in this repo - but it does include questions / components for this particular piece of research in addition to the guidelines for running causal modelling sessions with domain experts. There is also a .pdf file of "dag-dialogue-prompts.pdf" that offer suggestions for the facilitator based on sub-graphs in the current graphical model.

## DAG analysis and results

All analysis in the .qmd file `elicited-DAG-analysis.qmd` however there is a viewable pdf render [here](https://htmlpreview.github.io/?https://anonymous.4open.science/r/assured-assessment-dag-analysis-531D/elicited-DAG-analysis.pdf). The analysis is broken into three sections: importing the data, a series of causal graph analysis functions, a series of visualisations. There is a lot more here than what might be deemed necessary (exploration was happening), so the key exploration plots are included below.
